# 01: Start the web app with a synthetic reference example

**What to build:** A user can open a React and TypeScript web app and inspect the supported synthetic front and back reference geometry through the public generation boundary.

**Blocked by:** None (can start immediately).

**Status:** ready-for-agent

- [ ] The browser app runs and presents the synthetic front/back reference example in separate local coordinate systems.
- [ ] The example uses only explicitly supported reference geometry and is marked `SYNTHETIC TEST DATA - NOT AN ANTHROPOMETRIC STANDARD` and `REFERENCE GEOMETRY - NOT A PRODUCTION PATTERN` near the relevant data and output.
- [ ] A React-independent TypeScript geometry/generation module can be exercised through a public boundary, with an automated test covering the example's observable output.
- [ ] The example does not imply fit verification, physical measurement guidance, anthropometric validity, or production readiness.
