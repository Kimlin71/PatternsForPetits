# Domain Docs

## Before exploring

- Read the root `CONTEXT.md`.
- Read relevant ADRs in `docs/adr/`.
- If a referenced file does not exist, proceed without treating its absence as an error.

## Use the glossary

Use domain terms as defined in `CONTEXT.md`. If a needed concept is missing, flag the gap rather than silently inventing terminology.

## ADR conflicts

Surface conflicts with relevant ADRs explicitly rather than silently overriding them.

## Layout

This repository uses a single-context layout: root `CONTEXT.md` and root `docs/adr/`.
